# 钢丝试井数据智能分析系统（增强版）

## 技术栈
- Java 8
- Spring Boot 2.7.5
- Maven
- MySQL 5.7 / 8.0
- Thymeleaf + 原生 CSS

## 已实现功能（V2.0增强版）
1. 登录与会话拦截（演示账号 admin / admin123）
2. 运行总览：井筒数、任务数、待处理预警、平均测试深度、近期任务
3. 井筒档案：新增、列表、删除
4. 试井任务：任务登记、列表、删除
5. 数据采集：手工录入、CSV批量导入、最近300条数据查询
6. 智能分析：批量张力阈值判别、风险等级、分析结论
7. 预警中心：待处理/已处理状态、标记处理
8. 分析报告：任务汇总、浏览器打印/另存PDF
9. 分析规则台账：阈值配置记录
10. 试井曲线分析：深度/张力、速度/压力双曲线，井筒筛选，原生 Canvas 绘图
11. 井间作业对比：按井汇总任务量、平均深度、最大深度、平均张力
12. 报告 CSV 导出：可下载任务汇总 CSV
13. 采集点异常扫描：批量分析时扫描采集点张力、速度、压力并生成预警

## 快速运行
1. 安装 JDK 8、Maven、MySQL。
2. 创建数据库：
   `CREATE DATABASE wireline_db DEFAULT CHARACTER SET utf8mb4;`
3. 修改 `src/main/resources/application.yml` 中的 MySQL 用户名和密码。
4. 在 IDEA 中以 Maven 项目导入，等待依赖下载。
5. 运行 `WirelineApplication.java`。
6. 浏览器访问 `http://localhost:8080`。

默认账号：`admin`；默认密码：`admin123`。

## CSV格式
首行为表头，后续每行：
`采集时间,深度,张力,速度,压力`
例如：
`2026-11-18 09:30:00,1250.5,11.2,18.0,8.6`

## 重要说明
本项目为可运行的业务演示与二次开发基础版本。当前智能分析为规则阈值辅助判断，不是经过现场标定的专业诊断模型；示例数据仅用于展示。请根据油田现场设备、钢丝规格、作业规程和企业标准重新标定阈值，并由专业人员复核后用于生产决策。正式部署前应增加密码哈希、权限角色、操作审计、导入事务与数据校验、备份和安全配置。

## V2.0升级说明
新增曲线分析、井间对比、CSV报告导出，以及对采集点的张力/速度/压力辅助异常扫描。曲线图采用浏览器 Canvas 绘制，不依赖外部图表 CDN。

## V2.0 运行提示
数据库首次启动时由 Spring SQL 初始化脚本创建新增审计表。若项目数据库已存在且初始化脚本未执行，可手动执行 schema.sql 中 operation_log 的 CREATE TABLE 语句。
诊断规则属于演示用启发式规则，张力/速度/压力/深度阈值必须按现场设备、钢丝规格、井况及企业规程进行校准；不得将其作为自动停机、安全联锁或生产决策的唯一依据。
